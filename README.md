# A.J. Lawrence: skills

These are the skills I run on my own businesses for marketing and growth, packaged so you can run them in your own AI. They're free.

A lot of the tactical stuff is already out there in good open-source skills, and I use them. Honestly, a good CMO executes about the same as a really good tactical person. Where they earn their money is where they position you and what they feed into that work. That's the part I'm packaging here.

## The skills

Nothing is up yet. The first one is a goal interview. It asks what you actually want from the next six months, then checks whether you have what you need to hit it and whether you can even measure it. I'm a good example of why that matters, because my own predictions were running almost double what actually happened until I had a real baseline. It goes up here once I've run it on myself and a couple of other people, and I'll say on the show and in the newsletter when it's there.

## How to use one

You don't read the file. You give it to your AI, and the AI runs it with you.

- **Claude or ChatGPT in a browser:** download the skill's `SKILL.md`, attach it to a new chat, and say "Run this with me."
- **The Claude app, kept for later:** download the zip from [Releases](https://github.com/ajlawrence/skills/releases), then upload it under Settings, Capabilities, Skills.
- **Claude Code and other agents:** `npx skills add ajlawrence/skills`, or copy the folder into `~/.claude/skills/`.

Each folder follows the [Agent Skills](https://agentskills.io) open standard, so it runs in any agent that supports it.

## Feedback

Each skill ends by writing a short block about where it broke and what felt wrong. Paste it into the form at https://ajlawrence.com/skills/ and it reaches me. Nothing sends itself. For a technical problem, open an issue here.

When a run shows me something I got wrong, I change the skill and write down why in [CHANGELOG.md](CHANGELOG.md).
